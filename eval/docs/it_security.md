# IT Security Standard

## Passwords

Passwords must be at least 14 characters long. Passwords must be changed every 365 days. Password reuse across systems is prohibited.

## Devices

Company laptops must use full-disk encryption. Lost or stolen devices must be reported to the Security Desk within 24 hours.

## Data Classification

| Level | Example | Sharing |
|---|---|---|
| Public | Marketing brochure | Anyone |
| Internal | Org chart | Employees only |
| Confidential | Customer contracts | Named recipients only |

## Incident Response

Security incidents are triaged within 4 hours. Critical incidents are escalated to the CISO immediately.
